## 🌟 核心特色

- **地理空间科研足迹**：将学者的论文出版地、合作机构与参会轨迹绘制在交互式世界地图上。
- **合作者关系网络**：可视化呈现核心合著者集群与跨国研究网络。
- **学术成果成长树**：时间轴直观回顾学者的第一篇顶刊到当前成果历程。
