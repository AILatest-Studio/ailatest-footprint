## 🌟 核心功能

1. **地理空间科研足迹交互地图**：将学者的历年论文发表期刊出版地、国际会议参会城市绘制在交互式三维/二维世界地图上。
2. **全球学术合作关系网络**：立体呈现学者与跨国、跨机构研究者的合作频次与合著网络集群。
3. **科研成果成长时间轴**：从早期的第一篇论文到当前顶刊，全生命周期回溯科研旅途的学术里程碑。
